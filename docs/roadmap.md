# Roadmap

## Phase 1

- Auth, tenants, RBAC
- Doctor and chamber setup
- Patient registration
- Medicine CSV import and search
- Structured prescription builder
- PDF/print data and QR verification

## Phase 2

- Assistant workflow
- Chamber-wise serial display
- Prescription templates
- Server-side PDF generation
- Immutable signed prescription policy
- SMS reminders

## Phase 3

- Offline prescription drafts with IndexedDB
- Background sync after reconnect
- Subscription billing
- bKash/Nagad/SSLCommerz integration
- Advanced reports

## Phase 4

- Drug interaction checker
- AI prescription draft assistance
- Bangla voice input
- OCR handwritten prescription scanner
- Diagnosis suggestions
